# De'Tech - Jasa Layanan Digital

## Deskripsi Project

De'Tech adalah website company profile yang menyediakan layanan digital modern untuk membantu bisnis berkembang melalui teknologi dan inovasi digital.

## Fitur Website

- Dark Mode Toggle
- Portfolio Filter
- Contact Form Validation
- FAQ Accordion
- Scroll Reveal Animation
- Back To Top Button

## Teknologi yang Digunakan

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Manipulasi DOM

1. Dark Mode Toggle
2. Portfolio Filter
3. Contact Form Validation
4. FAQ Accordion
5. Scroll Reveal Animation
6. Back To Top Button

## Referensi Desain

- https://startbootstrap.com/theme/agency

Desain dimodifikasi pada:
- warna
- layout
- konten
- fitur interaktif
